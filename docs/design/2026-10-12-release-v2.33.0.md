# v2.33.0 · 源稿保真与结构化关系页

整合本地 WIP 快照与主干的 Fantasy Rainbow 商业布局，保留 bento、四款动效封面和离线播放。新增结构化关系页及独立源稿保真校验，不丢弃任一边的功能。

## 用户可见变化

- BRIEF 支持 5–40 页；40 页的导航点分列，避免末页按钮被播放入口遮挡。
- 奇幻彩虹新增分层架构、分层调用图、互动流程与投票，以及架构栈、上下文矩阵、调用链、双轨模式、工作坊、能力图和比较表等场景。结构化页保留分组、节点、关系、横切栏、底部 band 和来源引用；正文保持可编辑 DOM。
- 结构化关系内容优先于通用布局，显式 bento 选择继续生效。源稿提供的比较表标题、结论及中点分隔文字可保留，旧三列表格继续兼容。
- 新增 `scripts/validate_source_fidelity.py`，按页检查正文保留率、关系保留率和受保护事实。正文与关系阈值分别配置在 0.90–1.00，受保护项必须全部命中；备注、隐藏文本及截图不能替代正文。
- `--model-context` 识别 schema 引用并提供奇幻彩虹的结构化内容 schema，页数说明与实际门禁一致。其他 preset 的精简契约不提供不受支持的结构化能力。
- 修复快照整合时被覆盖的 bento 路由/样式、三款新动效主题渲染分流、GPU 降级封面和静态生成处理；补齐新增场景的手机布局。
- 同步 Skill 版本、中英文下载入口、当前 Demo 水印和发布说明。显式 tag 触发发布，避免同一次主干与 tag 推送同时发布相同资产。

## 源稿保真检查

先运行正式生成，再执行独立的覆盖检查：

```bash
python main.py --generate --brief BRIEF.json --output deck.html
python scripts/validate_source_fidelity.py deck.html content-coverage.json --report fidelity-report.json
```

覆盖文件必须列出实际 deck 的每一页，页码从 1 连续排列；下例展示一页的字段形状：

```json
{
  "thresholds": {"text_retention": 0.90, "relation_retention": 0.90},
  "slides": [{
    "slide_number": 1,
    "units": [{"id": "condition", "text": "审批通过后再提交", "weight": 1, "protected": true}],
    "relations": []
  }]
}
```

关系项包含 `id`、`type`、`from`、`to`、`weight`、`protected`，对应可见 DOM 的稳定 node/group ID 与关系标记。检查支持显式连线、包含、DOM 顺序等关系。返回码 0 为通过，1 为覆盖失败，2 为输入或文件错误。这是归一化精确文本与 DOM 关系检查，不是 NLP 语义判断；覆盖文件及来源真实性仍需核对。

## 发布验收与边界

- Python 3.13.15 完整非 slow 回归：3085 passed、119 skipped、8 deselected，零失败。跳过及 slow 用例不算通过。
- 从发行 ZIP 解压后通过正式 CLI 生成 7 个样例，覆盖：三类结构化关系页、扩展角色页、上下文矩阵、bento 和三款新增封面。8 页结构化样例的受保护正文及关系全部命中，逐页保留率均为 100%。
- 7 个生成样例在 Chrome/Playwright 中通过 1600×900、1280×720、1440×733 的窗口/播放模式，以及 390×844 手机布局检查。断网 file:// 下的方向键、F5、编辑备注、封面暂停/返回恢复通过；页面身份和正文有效，零页面异常、零 console error、零外部请求。浏览器报告中可能出现 WebGL ReadPixels 性能警告，不等同于功能错误。本会话没有 Browser 插件，使用仓库已有的 Playwright/Chrome 验证路径。
- 40 页解压包生成通过 strict 检查，40 个导航点可访问，末页跳转、F5 播放及返回首页通过。
- 全部 22 个内置 preset × 3 类输入共 66 例的扩展浏览器/风格门禁**未全绿**：5 个 native preset 的 15 例通过，17 个历史 profile preset 的 51 例存在溢出、对比度或风格契约问题。只看 strict HTML 检查为 51 例通过、15 例失败。
- 对照 SHA-256 已验证的 v2.32.0 发布 ZIP：66/66 生成 HTML 在仅归一化版本元数据后逐字节一致，strict 失败项逐例一致，新增回归为 0。最终包再次生成的 66 例与已测浏览器 HTML 一致；相同字节复用浏览器证据，新增/变更的奇幻彩虹场景重新测量。历史失败未删除、未放宽门禁，也未宣称此次修复了所有 profile preset。
- HTML/PPTX/PNG 生成意图检查与真实 PPTX 文件导出属于不同验收层；本次未运行 `--pptx-export`，未运行新的模型 prompt-to-deck 评测，也未覆盖全部浏览器/GPU。
