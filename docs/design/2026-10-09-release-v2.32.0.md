# v2.32.0 · 动效封面与离线播放

## 用户可见变化

- 新增极光封面、熔金流体和星核跃迁，与既有奇幻彩虹组成四款动效封面。
- 默认仅首页动态，正文和收尾静态；用户直接说主题名称，或问“有哪些动效封面？给我看预览”。
- 单 HTML 双击、断网和 HTTP/IP 都能自动播放 WebGL 动效，无需启动服务或安装浏览器运行依赖。极光封面在支持的 HTTPS 环境优先使用 WebGPU。
- 离开封面、后台、黑屏、打印或减少动态效果时停止绘制；返回符合条件的首页后恢复单个动画循环。
- GPU 不可用及静态导出使用细节完整的内嵌封面图，三款新主题的 PPTX/PNG 生成意图移除 canvas 与 GPU 初始化代码。
- 星核保留中心24秒一圈，中层72秒、外围144秒；外围拖尾缩短、减淡，避免整片远端粒子沿用中心转速。
- 中英文 README 提供四款目录、预览、提示词、新版下载和版本日志。

## 实际验证

- 完整非 slow 回归：3042 passed、123 skipped、8 deselected，零失败。
- 从实际 ZIP 解压后的运行字节验证：22 个内置 preset × 3 类公开输入共66例，以及四款动效主题 × HTML/PPTX/PNG 意图共12例，78/78 strict 生成通过。
- 最小生成环境为 Python 3.13.15 与 requirements-runtime.txt 中的 beautifulsoup4 及其依赖；普通生成不依赖 Playwright/Pillow。
- 四款解压生成稿在 Chrome 中断网以 file:// 打开：首页持续绘制，正文停止，返回首页恢复，零页面异常、零外部请求。
- 新主题的桌面窗口/播放模式、390×844 手机几何和真实六页 PPTX 冒烟通过。
- 新运行包保留上一版20个已发布企业主题文件，不从本地 ignored 目录自动收集私有资产。Cloudhub 的既有可执行布局限制继续保留，不宣称已修复。

这些检查验证程序、运行时和发行包，不是新的模型端到端任务评测。此前 README 中的模型质量、标题来源复核和安装环境限制仍然适用；本次图形验证使用 Chrome，未宣称覆盖所有浏览器/GPU。

## 安装与打包

下载 kai-slide-creator-v2.32.0-skill-runtime.zip，将顶层 kai-slide-creator/ 解压到 agent 的 skills 目录。需要生成时按包内 scripts/requirements-runtime.txt 安装 Python 依赖；已经生成的 HTML 只需浏览器。

发行包只含 SKILL.md、main.py、scripts/、schemas/、references/、themes/，不含源码仓库 README、Demo、tests、eval、设计文档、缓存与 Git 元数据。运行 manifest 和 ZIP SHA-256 随 Release 发布，执行权限保留。独立优化方法论继续使用 v1.0.1，不在此次版本中修改。

显式推送的版本 tag 触发 GitHub Actions：校验 tag 与 SKILL 版本及提交一致，从 Git index 运行字节打包，验证上一已发布企业资产的 SHA-256，从解压包执行三款新主题生成检查，上传 ZIP/校验和/运行 manifest 后将 Release 发布为 Latest。
