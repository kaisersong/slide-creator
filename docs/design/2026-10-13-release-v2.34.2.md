本版包含全部 8 个本地 WIP 文件、15 类 Fantasy Rainbow 结构页、可见关系线、禁止文案/结构保真检查，以及 v2.34.1 的共享导航竞态修复。原始 WIP 快照、历史 stash、未发布的失败 tag 与日志均保留。

## Linux 恢复失败的根因

v2.34.0 和 v2.34.1 的本地验收通过，但 Linux 全量回归在 Shader Hero 的 WebGL 上下文恢复用例中失败，Release 发布步骤均被阻止。对应 CI 为 38341619856、38344749282，专项复现为 38345381702。

诊断确认封面已回到视口且 .visible 正确，但 ready=false、RAF 停止、reason=null。本地强制软件 WebGL 复现同样状态；确定性浏览器用例进一步证明：loseContext() 立即使 GL 上下文失效，而 webglcontextlost DOM 事件稍后送达。期间绘制抛出 context-lost，被通用绘制失败路径设为 failed=true。随后恢复事件只清空 reason，永久失败标志阻止重建。

Shader Hero 现在把这种上下文丢失按可恢复生命周期处理：绘制和 DOM 事件共用 suspendWebGL，暂停并释放失效资源，恢复后仅在封面可见时重建。真正的绘制/初始化错误继续进入既有失败路径。没有改变原验收等待时限、跳过失败用例或降低门禁要求。

新增真实浏览器回归在 DOM 丢失事件送达前同步强制绘制；旧运行代码确定进入 failed=true，修复后保持可恢复并在返回封面时持续绘制。QA 状态公开 failed/glLost，失败时记录 GPU 状态、视口与控制台；独立诊断 workflow 不发布资产。

运行包含 214 个文件，20 个已发布企业主题资产从 v2.33.2 保留，34 个 profile 模板源/安装路径继续一致。核对 Git 提交字节、权限、ZIP/manifest/checksum 和 hosted download 字节一致。

此次是生成器与运行包验收，未运行用户原始 PPTX 的逐页视觉复核或新的真实 PPTX 文件导出。
