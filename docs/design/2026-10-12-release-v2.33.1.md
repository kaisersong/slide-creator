# v2.33.1 · 修复安装包的 17 个 profile preset

v2.33.0 的完整门禁没有全绿，不能把“与历史版本相比无新增回归”替代为“验证通过”。本版修复全部 17 个 profile preset 在安装包中的失败，发布前要求完整门禁通过。

## 根因与修复

源码中的 profile renderer 依赖仓库的 demos/。精简运行 ZIP 按设计不包含 Demo，安装后进入通用 profile 回退，丢失经验证的布局、排版、颜色和风格组件。源码测试与用户安装包实际运行的路径不一致，导致 51 个 profile 案例出现标题/正文溢出、手机裁切、对比度和风格契约失败。

- 把 17 个 preset × 中英文共 34 份 CSS/内容模板提取为正式 references/profile-templates/ 运行资产，不携带 Demo 的播放脚本或开发目录；生成器继续复用共享 runtime。
- 源码及安装包都读取同一套运行模板；运行根目录识别不再依赖 demos/，也不会越过安装目录读取外层仓库。
- 增加模板 manifest，打包时按已声明的 profile registry 核对两种语言、文件存在性及 SHA-256。缺失或篡改时阻止产出 ZIP。
- 缺失运行模板时拒绝生成，提示重装完整运行包，保留已有输出，不再悄悄退回未验证的通用布局。
- 加入 34 个独立 Python 进程的源码/安装包一致性用例，以及缺失资产、校验和错误和已有产物保全检查。
- GitHub 发布流程在上传资产前执行模板同步检查、安装包回归和完整 66 例浏览器/风格门禁；失败报告与截图保存为 Actions artifact。

## 实际验收

- 最终 ZIP 解压后的完整 preset-surface-all 门禁：22 个内置 preset × 3 类输入共 66 例，66 passed、0 failed。包括原来失败的 17 个 profile、51 个案例。
- 每例执行 strict HTML、preset contract/style fidelity、runtime fidelity、export DOM smoke、桌面窗口/播放模式和手机几何检查。桌面为 1600×900、1280×720、1440×733；手机为 390×844。没有删案例、关闭原门禁或改低阈值。
- 源码/安装包独立进程对照：17 个 profile × 中英文共 34 例，安装目录没有 demos/，输出逐字节一致；外层仓库的 demos/ 不能干扰安装包根目录。
- 完整非 slow 回归：3118 passed、123 skipped、8 deselected，0 failed。此计数来自隔离工作区；未复制本地主工作区的 ignored 企业开发夹具，跳过及 slow 用例不算通过。
- 发行 ZIP 包含 212 个运行文件，模板完整性、manifest 校验和、Git index 字节及权限、ZIP 完整性通过；20 个已发布 Cloudhub/Kingdee 企业主题文件从 v2.33.0 包保留并逐字节比对。
- 本地浏览器为 Chrome/Playwright。本会话没有 Browser 插件，使用仓库现有浏览器 QA；本次是程序及发行包验收，没有运行新的模型 prompt-to-deck 评测或真实 PPTX 文件导出。

v2.33.0 的原始失败报告和发布记录保留，本次使用新的 v2.33.1 tag 和资产，不覆盖旧 tag 或重写历史证据。v2.33.0 的源稿保真、结构化关系页、40 页支持、bento 和四款动效封面继续保留。

## 安装

下载 kai-slide-creator-v2.33.1-skill-runtime.zip，把顶层 kai-slide-creator/ 解压到 agent 的 skills 目录。普通生成继续只需 scripts/requirements-runtime.txt 中的依赖；requirements-release.txt 用于发布验收，不是普通生成的安装要求。
