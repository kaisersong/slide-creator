# Skill 优化方法论版本记录

方法论版本与 Skill 实现、语料、评分器及验收政策版本分别记录。新 bug 通过项目内 bug 记录推进；已结束的模型收据和快照不覆写。

## 1.0.1

日期：2026-10-08。

补充发布检查发现的实际bug：历史自定义主题依赖starter提供备注样式，共享编辑壳子没有补齐默认隐藏/打开；一个声称strict的回归实际使用strict=False；大字号暴露能力矩阵中12个小屏/长版式失败。强化“检查真实断言与发行包、扩大能力矩阵、重排保留内容、区分冻结模型证据与包验证”的现有原则，新增[bug记录](case-study/release-checks-bug.md)。计量与采用门槛不变，原1.0版本由Git提交和此前本地ZIP保留。

## 1.0

日期：2026-10-07。

建立基于 slide-creator 实测的首次方法论：任务和来源边界、隔离基线、真实 usage 计量、模型与程序职责、中间表示、渐进式披露、固定输入对照、完整任务评测、独立来源审查、真实交付验证及采用判断。提供优化计划、评测报告与 bug 记录模板。

登记的重要反例包括：精简上下文后的内容承载缺陷，数字对象/单位错配，实际播放检查器误判，重复诊断漏组件，指定风格没有独立约束，以及自动26/26通过但标题来源审查仍不通过。

案例状态：风格选择修复已完成，全部自动评测通过；默认采用仍因标题来源问题暂缓。方法论1.0不是案例全质量验收证明。

后续方法更新继续按实际bug与验证推进。版本规则及补验证要求见[方法论](README.md)，实际 bug 按[记录模板](templates/bug-record.md)归档。
