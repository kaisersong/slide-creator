# Skill 优化方法

[Skill 优化方法论](skill-optimization/README.md)当前版本为1.0，日期2026-10-07。包含完整执行步骤、检查层、踩坑案例，以及可复制的优化计划、评测报告和bug记录模板。

该方法来自slide-creator的实际效率与质量实验，支持其他Skill按自己的任务和风险建立基线。方法版本可复用，但不代表案例所有人工质量问题已通过验收。

后续发现Skill bug时，按[bug模板](skill-optimization/templates/bug-record.md)复现与验证，判断是否需要调整方法、模板或计量口径，再更新[版本记录](skill-optimization/CHANGELOG.md)。Skill实现与方法论分别版本管理；历史收据和反例保留。
